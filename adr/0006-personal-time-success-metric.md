# 0006: Personal time success metric

**Date**: 2026-05-31
**Status**: Accepted

## Context

GTD systems and productivity tools are designed around work output metrics: tasks completed,
deliverables produced, commitments kept. Applying the same framework to personal time creates
a structural problem: rest, recovery, connection, and enjoyment score zero on work output
metrics — not because they failed, but because the metric is wrong. This generates
unavoidable shame and keeps the "not enough" loop open through the evening, which prevents
genuine recovery. The ADHD rejection sensitivity and tendency toward self-criticism makes
this loop especially corrosive.

## Decision

Personal time uses a different success metric than work time.

**Work time:** measured by output, business value, and commitments kept.

**Personal time:** measured by restoration, connection, and care. Success conditions:
Was energy restored? Was something meaningful experienced? Was care taken of self or others?

The evening sweep marks the personal day complete on its own terms. "The personal day is
complete" is the right frame — not "I didn't do enough."

Using the right metric is not lowering the bar. It also closes the cognitive loop:
completion requires a success condition that can actually be met.

## Alternatives considered

**Single metric (output) for both work and personal** — rejected. Rest, recovery, and
enjoyment cannot be evaluated on an output scale. Applying work metrics to personal time
makes genuine recovery structurally impossible to "succeed" at. The shame is not incidental
— it is the inevitable result of a wrong measurement.

**No explicit metric for personal time** — rejected. Without a named success condition, the
default metric (work output) fills the gap. The same shame loop results, but without the
user being aware it's a category error.

## Consequences

- The evening sweep's job is to close the cognitive loop so the rest of the evening is
  guilt-free — not to produce a productivity report.
- When the user measures personal time by work standards, name the category error
  explicitly. This is a coaching intervention, not a correction.
- The personal Highlight is about one meaningful self-directed win, not maximum task
  throughput. Its value is shape and closure, not output volume.
- Design implication: personal evening time should be protected for restoration activities
  (interest-driven, novelty, mastery, rest), not stacked with obligations that score well
  on work metrics but drain rather than restore.
